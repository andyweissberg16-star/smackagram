Two-factor authentication

Separate switches because the risk differs. An admin account can see every customer’s details and hand out credit, so you may want it protected even while customer 2FA is off.

ADMIN_BYPASS_2FA is set in Render. Admin 2FA will show as on but won’t actually be enforced. Remove that variable once texts are arriving reliably.
Customers
Texted a code at registration and every login.
Admins
Protects this panel, customer data and credit grants.

Before turning on admin 2FA

Texts are currently unreliable — Twilio reports them sent but they don’t always arrive, pending A2P approval. If you switch admin 2FA on and no code reaches you, you lose access to this page, including the switch that would turn it back off.

Safe order: set ADMIN_BYPASS_2FA=1 in Render, turn this on, confirm a real code arrives, then remove the variable.
